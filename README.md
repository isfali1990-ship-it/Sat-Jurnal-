# Satış Jurnalı

Gündəlik satış Excel hesabatını yükləyib yoxlayan, düzəldən və Zavod 1 / Zavod 2 üzrə canlı göstərən sayt.

- Statik sayt: `index.html` (Vercel-də build lazım deyil)
- Baza və login: Supabase layihəsi `satis-jurnali` (`picziajcjpfiwclgamop`)

## Rollar
- **Admin** — hər şey, istifadəçilərə rol verir
- **Yükləyən** — Excel yükləyir, zavod seçir
- **Baxan** — yalnız baxır
- **Gözləyir** — yeni qeydiyyat, heç nə görmür
